SECURE DOCUMENT PROCESS

Identity documents are handled through an approved process

Because Aadhaar and similar identity documents contain sensitive personal information, this public website does not collect Aadhaar numbers or Aadhaar uploads. If the school administration later approves Aadhaar collection, it should be done only through a school-controlled, authenticated document process with limited staff access, encrypted transfer/storage, access logs, and a defined retention/deletion policy.
